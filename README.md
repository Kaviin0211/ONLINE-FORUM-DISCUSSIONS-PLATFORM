# ONLINE-FORUM-DISCUSSIONS-PLATFORM
Interactive Online Forum Discussion Platform built using HTML, CSS, JavaScript, and jQuery with post reactions, comments, and responsive design.

A responsive and interactive Online Forum Discussion platform developed using HTML, CSS, JavaScript, and jQuery. This project allows users to participate in discussions, post comments, react to posts, and engage in community conversations through a clean and user-friendly interface.

## 📌 Project Overview

The Online Forum Discussion System is a web-based platform designed to facilitate discussions on various topics. Users can view discussion posts, interact through comments, and express opinions using like and dislike reactions.

This project demonstrates front-end web development concepts including responsive design, DOM manipulation, event handling, and interactive user interfaces.

## 🚀 Features

- View discussion topics and posts
- Like and dislike reactions
- Nested comment section
- Comment input functionality
- Interactive user interface
- Responsive design
- Dynamic post interactions using jQuery
- Clean and modern layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery
- Font Awesome
